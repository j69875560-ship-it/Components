# Portfolio Platform

A modern, responsive Single Page Application (SPA) built with React to showcase creative projects. Features dynamic project management, real-time search filtering, and an intuitive form for adding new portfolio items.

## Features

- **Project Showcase** — Displays a responsive grid of portfolio projects with images, descriptions, and category badges
- **Dynamic Search** — Real-time filtering by title, description, or category as you type
- **Add Projects** — Expandable, validated form to dynamically add new projects to the portfolio
- **Delete Projects** — Remove individual projects with hover-to-reveal delete controls
- **Responsive Design** — Mobile-first layout that adapts seamlessly from phones to desktops
- **Modern UI** — Clean professional aesthetic with smooth transitions and hover effects

## Tech Stack

- **React 18** — Functional components with Hooks (`useState`)
- **CSS3** — Custom properties, Flexbox, CSS Grid, and responsive media queries
- **Vite** — Fast development build tool
